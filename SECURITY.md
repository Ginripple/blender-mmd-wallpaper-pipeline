# Security

The bundled helper scripts are intended for local project inspection. They do not require network access, credentials, or shell execution.

Before accepting a contribution that adds network requests, subprocess/shell execution, destructive filesystem operations, automatic `.blend` saving, or model-asset rewriting, review that change as a security/safety-sensitive expansion of scope.

When reporting a security concern, include the affected script, exact invocation, observed behavior, and whether project/source files were modified.
